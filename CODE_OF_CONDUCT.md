# Código de conduta

Este projeto é um espaço colaborativo para experimentos pessoais. Queremos que todas as interações sejam respeitosas, construtivas e inclusivas.

## Comportamentos esperados

* Tratar todas as pessoas com respeito e empatia.
* Fazer críticas técnicas focadas no código, na documentação ou na proposta — nunca na pessoa.
* Usar linguagem clara e acolher perguntas, diferentes níveis de experiência e pontos de vista.
* Aceitar feedback com abertura e ajudar a manter as discussões objetivas.

## Comportamentos inaceitáveis

* Assédio, discriminação, ameaças, ataques pessoais ou linguagem ofensiva.
* Publicação de dados pessoais, credenciais ou conteúdo privado sem autorização.
* Spam, trolling, discussões deliberadamente hostis ou qualquer comportamento que impeça a colaboração.

## Aplicação

Comentários ou contribuições que violem este código podem ser removidos. Casos de comportamento inadequado devem ser reportados ao mantenedor por uma discussão privada no GitHub ou pelo canal de contato disponível em [ronanrodrigo.dev](https://ronanrodrigo.dev).

Este documento foi adaptado para este projeto a partir dos princípios do [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
